# 捞尸人（更新至593章）

<b style='color:orange'>作者：纯洁滴小龙</b>

> 一墙之隔，两张床。

> 西边床上，李三江眉头紧皱，不时发出呓语，手脚不规则地甩动。

> 可尽管有这么大的反应，他却依旧无法从额梦中苏醒。

> 冥冥之中，仿佛有一个看不见的人，正压在自己身上。

> 对方很沉，压得自己胸闷，近乎无法呼吸。

> 可任凭自己怎么努力，都无法将其推开。李三江自己都没料到，背了一辈子诗的自己，竟然有一天会被瑰压床。
