# 最最最简单的workbuddy换肤方案！赶紧安排起来！

![](https://files.mdnice.com/user/40283/1bfbc540-3fcc-4e3c-8529-53eaff4734ed.jpg)

本期是继续上一期的内容，这有一个更简单的办法去修改你的**workbuddy**皮肤！

- 关闭你正在使用的workbuddy
- 你只需要在你的本地AI助手中，给他说这么一句话：
```
用这个开源项目帮我更换 WorkBuddy 的主题https://github.com/cdredfox/workbuddy-skin-studio
```
就这两个步骤，你就能完成换肤！

>[!tip]
>注：这里的AI，会根据你给的地址，在你当前的文件夹下载这个代码保存到本地，再根据代码执行任务去换肤。


![换肤截图](https://files.mdnice.com/user/40283/315559a5-9f98-4088-948a-56dc2571c3cc.png)

当然，这里的**AI助手**说的是能控制你电脑的助手，比如我这里写代码用到的**codebuddy**、**Claude**、**Cursor**，实在不行你直接下载一个桌面的豆包，大概率也是没问题的。

我们打开**workbuddy**，可以看到右上角有一个按钮，这个按钮就是用去切换主题皮肤的。


![切换按钮](https://files.mdnice.com/user/40283/7a078e60-ef2a-4ce5-8147-9bfc4ee27c0b.png)

当然你也可以自定义图片，最好还是选择2k及以上的图片，这样会比较清晰一点。


![自定义图片](https://files.mdnice.com/user/40283/c9c80528-a6e8-47fd-b76c-e51c6a9f3cc8.jpg)


当你不再使用这个主题了，想换回以前的原生界面，直接右上角按钮里面选择原生界面即可。

至于想要卸载这个主题啥的，你直接把下载到安装包删除即可，再打开就没有了。

除了workbuddy外，其实codex也是能换肤的，上期和本期的内容其实基本上都是参考了codex换肤的方案去做的。
