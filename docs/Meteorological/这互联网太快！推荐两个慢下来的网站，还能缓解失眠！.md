# 这互联网太快！推荐两个慢下来的网站，还能缓解失眠！

![](https://mmbiz.qpic.cn/mmbiz_png/GLOg31lke1ft2kIK1MKlQEDdPEAaJXyEaWD2kVnkicpd8DD4HghRD5ve2YTnIgQ3vlvWGQ9JxrkztfAnV7MR8ZA0ibUdKwmEWia5S7XolQt71c/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0)

本期又找了两个网站，绝对很好用！两个让我们慢下来的网站！

## 1、Rainy Mood
网址：https://rainymood.com

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/GLOg31lke1eMnYzUjMWsWDRURu6EPts2H4XqONpWoMpuoVaJap4ibbaZ4j0o2y4M3q93HCHuibbiavHV7u0wYOm0yDpwwC0a1nRUtiagsbs5Mmo/640?wx_fmt=webp&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=1)
这是一个超级简单的网站，简单到有点过分，打开就是雨声，加上远处偶尔一声闷雷，然后一直循环。没有画面，没有按钮，没有「猜你喜欢」，就一个雨夜的窗户，雨一直下。 我头一回点开还以为卡了。

可你听着听着就发现，它那个雨声不是随便录的，是那种厚厚的、把整个房间裹起来的雨。你不是在听雨，是被雨罩住了。键盘敲字的声儿混进去，反而特别安心。

我现在的用法是，写东西的时候开它，睡觉之前也开它。说真的，比那些个要会员、要选歌单、还得看广告的白噪音 App 省心多了。它就一个功能，下雨，然后让你安静。

> 如果你失眠，可以用打开这个网站，听听白噪音，听说下雨声和睡眠声绝配。

## 2、The Useless Web
网址：https://theuselessweb.com

![](https://mmbiz.qpic.cn/mmbiz_jpg/GLOg31lke1dBTdL0N09PNcj7esgVwtAQibo76iaU6ZIQibvlosTaXb4vlfT1zxNvBSsQrZAqNfNiaOLxjcic1OIPW9xvI4OFPofzIYekJ0P7YcCA/640?wx_fmt=webp&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)
光听名字你就知道它不打算有用。

这站就一个按钮，点一下，把你随机丢到一个奇奇怪怪的网站去。可能是一个孤零零的按钮让你点，可能是一段莫名其妙的动画，也可能是一个你根本看不懂但就是想一直看的交互玩意儿。

像什么？像一台连着互联网的老虎机。你不知道下一把是什么，但每次拉杆都有种微小的期待。这感觉，怎么说呢，有点上头。。。

我前两天点了一下，跳到一个满屏都是猫在跑步的页面，我盯着看了得有三分钟，啥也没想。那种感觉很奇怪，平时我脑子里最少同时转着七八件事，那一会儿，全空了。

你有没发现，我们太缺这种「无目的」了。打开任何一个正经 App，它都想让你停留更久、买点什么、看点广告。可 The Useless Web 啥也不图，它就把你扔进一个没意义的小角落，让你当三分钟傻子。

**现在的互联网太急了，急得让人难受。每条内容都恨不得把你下一秒也吃掉，每个按钮都在算计你多停一秒。我们被训练得，连发呆都得有罪疚感，好像不干点什么就是浪费。**

老子讲无用之用，我以前觉得这是文人矫情。现在想想，*也许我们最缺的，就是这种明摆着没用的东西。* 它不帮你升职，不帮你省钱，不帮你变好，它就把你从那条永远停不下来的流水线上，暂时摘下来，放一会儿。

既然看到这里了，如果觉得不错，随手点个赞、在看、转发三连吧，如果想第一时间收到推送，也可以给我个星标⭐～
