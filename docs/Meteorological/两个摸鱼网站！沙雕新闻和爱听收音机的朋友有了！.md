# 两个摸鱼网站！沙雕新闻和爱听收音机的朋友有了！

本期推荐两个有意思的网站！大概你摸鱼的时候还是能用上的！

## 1、沙雕普拉斯
网址：https://shadiao.plus

![沙雕普拉斯](https://mmbiz.qpic.cn/mmbiz_png/GLOg31lke1cFVib9Fo8uHegStE8s6C7DvEsDTYWHsmAWRFQibkhia80oPPgiaWZW4RV7BbxnIcBoda6NrYa1eEX0XBXichuVIjBQ73BnEp1mvRZ0/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=1)

这个网站收集了网上各种各样的沙雕新闻，真正做到了我们不生产段子，我们只是新闻的搬运工。目前看也是随时会更新的。

比如：

- 上海一哥们去饭馆点了个 68 块的大盘鸡，端上来发现有土豆，他不乐意了，报警。最后呢，鸡吃光了，土豆也吃光了。
- 云南两个男的，学野鸡叫去打猎，一个在林子里咕咕咕，另一个听成真鸡，一枪过去打自己人身上。俩人双双进去。
- 还有更疯的。湖南一哥们在网上认识个对象，对方说要买坦克准备打仗，让他投钱，他真投了 42 万。42 万，买坦克。你现在去搜这新闻都还在。
- 我以为这就到顶了，结果还有。百色两个村民，为了博领导赏识，跑去挖领导家的祖坟。还有一哥们偷了一万多辆共享单车，一辆卖 105 块，偷得太快，收赃的反而欠了他二十多万。

没事空了看一看，心情不好也就好起来了！

## 2、网络收音机
网址：https://fm365.space

![](https://mmbiz.qpic.cn/sz_mmbiz_png/GLOg31lke1c5l8ibCIsT185VI5gPLlXJslGaKfMqia6VBpNRCEiaSmGNp21ia2eOM3G0jOc1knBgyfZ8KEdN1R2PQsPQNQzhib5EqUhFK2UjbMTc/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)
这个站牛在哪儿呢，不用下载，不用注册，打开网页就能听。界面干净得不像这个时代的产物，上面就几个字，搜索电台，长辈版，我的收藏，播放记录。

它把电台按省分好了，北京，上海，广东，四川，你要哪个点哪个。国家电台那一栏我最常用，中国之声，音乐之声，经济之声，交通广播，中央的那几个台全在。

而且还有长辈版，其实就是把字放大了，防止年纪大了看不清字体。

> 注：这两个网站也放在了导航网的摸鱼分类当中啦！
