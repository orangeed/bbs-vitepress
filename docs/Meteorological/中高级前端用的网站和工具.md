# 招聘上写的中高级前端都是在用什么网站和工具呢？从地图GIS到埋点，不要再只写页面啦

> 上一期写了前端入门的工具，这一期写写中高级前端大概涉及到的技术和网站。

作为一个前端开发，前一两年大概率确实是仅仅写页面，或者公司是物联网行业的，再写写`MQTT`通信之类的。

但是工作两年后，换工作的时候，你会发现很多也要求你会`GIS`或者说至少你还能学习新的技术。

比如第二份工作要求还要会`Bin`，但是我当时确实不会，但是我好在是还能学习。在之后又涉及到了`GIS`等相关的。

最简单的其实也就是国内的地图，使用他们的API，做一些地图展示，地图渲染点位或者点位弹窗等等。稍微复杂点的，就根据实际业务来做地图的路线规划或者导航。

- **高德地图开放平台：**https://lbs.amap.com
- **百度地图开放平台**：https://lbsyun.baidu.com


![高德地图开放平台](https://files.mdnice.com/user/40283/6b927a6f-fcd1-4342-b72c-6aa1bbebcba5.png)


当然，这都是基础的，有些项目可能要求你使用`Mars3D`、`OpenLayers`或者`Leaflet`。这个也是做`GIS`的技术，而且功能上面会更加强大一点，这里面除了本身的地图外，我们还可以接入第三方地图，比如`高德地图`、`百度地图`或者`天地图`。当然你如果做`GIS`，就知道其实标准的坐标系还是`WGS84`，只有`天地图`是这个坐标系的，其他两个都是拥有自己的坐标系，在实际的应用场景中，还需要转换才行。

- **Leaflet：**https://leafletjs.com
- **Mars3D：**https://mars3d.cn
- **OpenLayers：**https://openlayers.org

![OpenLayers](https://files.mdnice.com/user/40283/61dbc46d-1d48-48b3-8480-b1ba54b21c4d.png)

除了这些外，你的老板，可能还想要知道网站访问数量，又或者想知道用户分析数据等等，你或许可以用到以下的几个埋点工具：

- **Google Analytics：**https://analytics.google.com
- **百度统计：**https://tongji.baidu.com
- **友盟+：**https://www.umeng.com
- **神策数据：**https://www.sensorsdata.cn
- **Mixpanel：**https://mixpanel.com/home


![百度统计](https://files.mdnice.com/user/40283/1771db99-43f2-44bc-87b3-56f1e799cdfb.png)

你可能工作时间越长，公司的项目越多，环境就越复杂，每个项目的node版本也不一样，那么你就需要一个node版本管理器，我常用的还是`nvm`，也有其他的，但是还是习惯了这个：

- **nvm：**https://github.com/nvm-sh/nvm

如果你是windows，那你可以使用`nvm-windows`:

- **nvm-windows：**https://github.com/coreybutler/nvm-windows

以上，就是目前我想到的，在目前阶段用的一些网站或者工具。当然还有不少，比如`nginx`、`docker`或者`CI`工具。


![docker](https://files.mdnice.com/user/40283/d0e572e7-5c94-46f5-9253-be24bde668b0.png)


如果你还有什么好用的开发网站或者工具，不妨说说看吧。
