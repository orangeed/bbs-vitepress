# 那些玩出花来的摸鱼阅读神器，看看是怎么个事？

为了让摸鱼更加方便，我是发现了：

真的有很多摸鱼王者，甚至都是自己写软件来摸鱼。

我自己都没想到的新方式。

下面盘点几个**玩出花一样的摸鱼看书软件**。

## 1、fish-book

### 传送门：https://www.fish-book.com
### 传送门：https://pan.quark.cn/s/f89d85005d0d

这一看名称就很清楚的知道了。实在是太隐蔽了。

软件是开源免费的，支持 TXT、EPUB、MOBI 等多种格式，字体颜色、大小、行距均可自由调节。支持自动翻页、单键翻页，还贴心配备了老板键。每次打开都会自动恢复上次的窗口位置，配合搜索功能，快速定位想看的小说。

![fish-book](https://fish-book.com/images/preview_new.gif)



::: warning
**缺点也有**，软件下载下来有100多兆，后台占用的内存也大概是200多兆。
:::

你要是觉得这个比较大，那当然还是有小一点的。

## 2、Reader
### 传送门：https://github.com/binbyu/Reader
### 传送门：https://pan.quark.cn/s/c829539fd58e

这个软件的大小就可以说是非常之小了，**压缩包只有400多kb，解压完也才2MB，后台占用也才7兆不到，几乎忽略不计！**

但是你在使用之前一定需要提前阅读一些readme.txt，不然你可能不知道咋用呢。

比如按住 Ctrl + Shift + 鼠标滚轮 调节窗口透明度，拖动右下角自由调整窗口大小，摆放到合适位置后按 Ctrl + T 置顶窗口，再按 F12 隐藏边框，只留下纯净的文字阅读区。

字体、颜色、大小、字距、行间距均可自由定制。软件会自动解析 TXT 目录，方便快速跳转；若解析不准，可在「设置 → 高级设置」中手动调整。除了目录跳转，还支持快捷键添加书签和全文搜索。

翻页方式灵活多样：鼠标左右键翻页、单键翻页、自动翻页任你选择。想快速隐藏窗口？**同时按下鼠标左右键、ESC 键或自定义老板键即可一键隐身。**

更支持自定义或导入书源，直接在线阅读海量小说。

当你调整完配置后，你就可以这么看小说了。

## 3、伪Word浏览器

### 传送门：https://pan.quark.cn/s/e38054c9114e

这个就是牛了，本质上就是一个浏览器的内核，然后将外面的UI样式，给做成了Word的样子，套壳啊，我的天啦。
![软件界面](https://img.orangecj.cn/wx-editor/%E6%AD%A6%E5%8A%9F%E7%9B%96%E4%B8%96%E7%9A%84%E4%BD%A0/202610/20261014-949208f1dd50.png)

这个你能一下子看出来是在摸鱼看小说吗？

因为他是一个浏览器，所以你你可以不仅仅如截图一样的使用微信读书，你还可以使用起点，番茄，京东等等都行。

他还有一个快捷键，【空格】！！！一键切换到正常的伪装文档上去！

## 4、Legado

### 传送门：https://pan.quark.cn/s/2917d346867f

这是一个免费开源的阅读软件，是一款**免费、开源、无广告**的 Android 阅读工具，也有鸿蒙版和 JetBrains IDE 插件版。它不像普通书城 App 那样自带书籍，而是把阅读器和内容来源分开：软件本身是一个干净的“阅读壳”，用户通过导入“书源”规则，让它从指定网站抓取目录和正文；也可以直接阅读本地的 TXT、EPUB 等电子书。

**它的优势在于自由度高。**书源可以导入，也可以自己编写；阅读界面支持字体、字号、背景、行距、翻页模式、夜间模式等深度定制；还内置 TTS 朗读、内容净化、替换规则、书架分组、缓存、备份同步等功能。由于没有广告、推送和内购，阅读体验比较安静，适合喜欢自己管理书源、追求纯净阅读体验的用户。

不过它也有门槛：装好后书架是空的，需要手动导入书源或本地文件；书源质量参差不齐，部分可能失效或夹带不规范内容，使用时要注意来源可信、版权合规。如果你是 Android 用户，想摆脱广告和固定书城，Legado 很值得尝试；但如果你希望打开就能直接看推荐书，它可能不如传统阅读 App 省心。

但是正是因为他的灵活度很高，整个软件的皮肤甚至logo都能自定义，所以你可以做成微信的样式....或者你在网上搜一搜有没有喜欢的样式。
