代码块（自动语法高亮）

```js const a = 1; ```

语言标记会显示在代码块右上角，并决定高亮规则。支持 js / ts / vue / html / css / json / bash / py / java / go / c++ / c# / sql / php / yaml 等。

高亮引擎：已内置 highlight.js（lib/ 目录，整站部署或打包 App 均离线可用），高亮更准、语言更多；若这些文件缺失（比如只单独打开 HTML），自动回退到内置自研高亮。深色/跟随主题模式用自研高亮以匹配主题色。

高亮输出为内联样式，复制进公众号后颜色仍保留。右上角「语法高亮」勾选框可一键关闭。

图片与图注

![这里写图注，会显示在图片下方](图片地址)

直接 Ctrl+V 把截图粘进左侧编辑器即可：会自动压缩到 1080px 宽、转成内嵌数据，并插入 ![图片描述](...)——「图片描述」处于选中状态，直接打字就能写图注。拖拽图片文件进来同样可以。

注意：本地图片粘贴进公众号后会丢失。点左栏「图片清单」可一键下载全部本地图，传到公众号后台后把链接替换回 Markdown 即可。
