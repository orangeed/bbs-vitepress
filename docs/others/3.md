## 如何使用

这里举个例子，下载一个移动端（Android或者ios都行。）。

下载安装完后是如下的界面：

![](https://mp-r2.084817.xyz/mmbiz_qpic_cn/sz_mmbiz_jpg/GLOg31lke1eVjqZGJSZnobzwTiaGw7pl9RIEMFybVwoOluficGIU33XyhFOrDsQw6UdAD9ahk5lPL9XyFyK0pgavHNI8dCUUppDIicpy00gM28/640.other)

我们选择登录，然后点击资源库，你选择右上角的+，就可以导入云盘的资源了。

![](https://mp-r2.084817.xyz/mmbiz_qpic_cn/mmbiz_jpg/GLOg31lke1dBE0VKicnurZdmrbWvBRAxSpEoia8AkXD8XibOdkrK5typtLECM57HTq0jh6BGUvgnuEym64s2pn7psHgCQzxtByIJM2yDiaHZgZc/640.other)

可以看到这里有很多的资源可以添加，如果手机上安装了云盘，他就会提醒你有可以挂载的。没有下载的话，比如我没有安装百度网盘，也是一样的操作。

选择你需要挂载（导入）的云盘，然后正常登录，然后就需要选择你需要导入的文件夹了。比如我这里分类了，我只需要导入这一个文件夹即可。

![](https://mp-r2.084817.xyz/mmbiz_qpic_cn/mmbiz_jpg/GLOg31lke1enkvicyVDr6Vm9j9xcibjciaOKib2E0ibKjaQCaJ4OcbsjtTibBxEjE4BzqyEoY35pLibF25d1pZd1bLWuUubCxlalQEs5ZtSo7ALnick/640.other)

然后选择文件夹，点击导入即可。软件就会自己去扫描文件夹下面的资源，然后去匹配，进行海报刮削和分类，只需要稍等一会，就可以在媒体库看到了结果。

![](https://mp-r2.084817.xyz/mmbiz_qpic_cn/sz_mmbiz_jpg/GLOg31lke1dM3gbmMdohHVW1MYkxQzOzicdSfDzeRiciaETAtd5kmnrVk686bqMmNQ52aNvVm2UKtTAh8GH9h7K1BMbQ5bjZCrvXpWQnib3LZs8/640.other)

非常清晰的分类，如果云盘的资源更新了，你就可以点击右上角的刷新，就会再去扫描云盘的资源，进行识别。然后我们在点击进来看详情。

![](https://mp-r2.084817.xyz/mmbiz_qpic_cn/sz_mmbiz_jpg/GLOg31lke1ekzA6CXOk0MGuZyOkCDt48phRzIoZHXkiaKoMDhqrEIvrh2Xa1fBzZjNF4n4LNvWsSJc7F2dYo4U8d69tnBPo4f1DMjtazpaao/640.other)

还是比较好看的海报，下面有多少集，在下方还有演员以及简介等等，比较详细。

在移动端导入的资源，其他端只要登陆了这个账号，都可以使用这个资源进行观看了，所以你可以直接windows或者TV端登录即可！

也就是你只需要移动端只需要更新了资源，其他端都是可以收到更新，进行观看的！所以家里其他人也是可以看的哦！
