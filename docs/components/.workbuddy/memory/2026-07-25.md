# 2026-07-25

## CinemaBoxOffice.vue 新增时间筛选
- 给电影票房组件加了「时间筛选」功能：顶栏下方新增玻璃拟态筛选条（起始/结束日期 input + 本周/本月/本季/本年 预设 + 清除按钮）。
- 接口切换：无时间范围时仍用 `/movie/now_playing`；选定区间时改用 TMDB `/discover/movie`，传 `primary_release_date.gte/.lte` 并按 `sort_by=revenue.desc` 排序。
- 示例数据回退模式（无 apiKey）也支持按 release_date 字符串过滤。
- 顺手修掉先前版本遗留的 bug：`getListPage` 里引用了未定义的 `startDate`/`endDate`。
- 注意：TMDB 的 revenue 为全球累计票房，非分地区/时间窗口票房；discover 上 region 参数对纯日期筛选影响有限。
